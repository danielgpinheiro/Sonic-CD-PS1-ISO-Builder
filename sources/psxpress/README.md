# psxpress (modified) — MPL 2.0 source

`mdec.cpp` / `mdec.hh` are the MDEC + VLC video decoder compiled into `bin/SonicCD-PS1.exe`,
ported from PSn00bSDK's `libpsn00b/psxpress` (https://github.com/Lameguy64/PSn00bSDK) and modified
for the PS1 port (psyqo, C++). As required by the Mozilla Public License 2.0
(`../../licenses/MPL-2.0.txt`), the source of these modified files is provided here.
